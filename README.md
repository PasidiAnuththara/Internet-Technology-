# 🌐 HTML, CSS & JavaScript Learning Repository

Welcome to my Web Development Learning Repository! 🚀

This repository contains code examples, notes, and practice exercises to learn **HTML, CSS, and JavaScript** from the basics.

## 📚 Technologies Covered

### 🟠 HTML
- Basic HTML structure
- Headings, paragraphs, and links
- Images and lists
- Tables and forms
- Semantic HTML elements

### 🔵 CSS
- CSS selectors and properties
- Colors, fonts, and backgrounds
- Box model
- Flexbox and Grid
- Responsive web design
- Hover effects and animations

### 🟨 JavaScript
- Variables and data types
- Operators and functions
- Conditional statements
- Loops and arrays
- Objects
- DOM manipulation
- Event handling
- Form validation

## 🎯 Learning Goals

- Learn the fundamentals of web development.
- Practice HTML, CSS, and JavaScript coding.
- Understand how websites work.
- Build responsive and interactive web pages.
- Improve coding and problem-solving skills.

## 🛠️ Tools Used

- HTML5

- Git & GitHub
